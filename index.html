Supported Methods

Caesar Shifts letters by a fixed amount.
Vigenère Uses a repeating keyword to shift letters.
Vernam Uses a key for character-by-character XOR.
Rail Fence Rearranges text using a zigzag pattern.
Columnar Transposition Rearranges text using keyed columns.
AES Modern symmetric encryption using Web Crypto.
RSA Asymmetric encryption using a public/private key pair.
SHA-256 One-way cryptographic hashing.
